# Quantitative Finance Notes

Personal study notes and Python implementations in quantitative finance, developed as part of my MSc Computational Finance studies at King's College London.

This repository combines mathematical foundations, financial modelling, and numerical methods through Jupyter Notebooks.

## Topics

### 03. Covariance and Portfolio Selection

- Covariance matrices and multivariate normal distributions
- Cholesky decomposition and correlated random variables
- Markowitz portfolio theory and mean-variance optimisation
- Portfolio optimisation using Python
- Efficient frontier visualisation

### 04. Geometric Brownian Motion and Merton Problem

- Discrete-time Geometric Brownian Motion (GBM)
- Stock price simulation and visualisation using Python
- Utility functions and risk preferences
- Optimal consumption and investment decisions
- Infinite-horizon Merton problem

### 05. Wiener Processes and Stochastic Differential Equations

- Wiener process properties and simulation of Gaussian increments
- Brownian bridge construction and midpoint refinement
- Unit testing of stochastic simulations
- Brownian scaling and self-similarity
- Stochastic differential equations and the Euler–Maruyama method
- Continuous-time GBM and stock price simulation

## Tools

Python · NumPy · Matplotlib · Jupyter Notebook

## About

This repository is continuously updated as I progress through quantitative finance topics, with an emphasis on understanding the mathematical intuition and implementing financial models in Python.
